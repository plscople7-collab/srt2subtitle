# srt2subtitle beta

身内配布用のベータ版です。
音声/動画またはSRTを、話者別EXOテンプレートへ流し込んでAviUtl用EXOを生成します。

## 最短手順

1. `start_srt2subtitle.bat` をダブルクリックする
2. ブラウザで `http://127.0.0.1:8002/` が開く
3. 話者ごとに音声/動画またはSRTを入れる
4. プリセットを選ぶ、または見本EXOを入れる
5. `EXO自動保存` を押す

## 音声認識を使う場合

初回だけ `setup_whisper.bat` を実行します。

必要なもの:

- Windows
- Python 3.12
- インターネット接続

Whisper本体と関連ライブラリは重いため、配布ファイルには同梱していません。
セットアップ後、初回認識時にWhisperモデルのダウンロードが入ります。

## SRTからEXOだけ使う場合

Whisperセットアップは不要です。
`/v2` または統合画面でSRTとEXOテンプレートを指定してください。

## データ保存場所

- `data/v2/`: プリセットとプロジェクト
- `data/transcriber_cache/`: 音声認識キャッシュ
- `.tmp/`: 一時ファイル

配布されたフォルダ内だけで保存します。

## 注意

- フォルダ名に記号が多い場所、OneDrive同期中の場所、管理者権限が必要な場所では失敗することがあります。
- うまく起動しない場合は、フォルダを `C:\tools\srt2subtitle-beta` などに移してから再実行してください。
- セキュリティ警告が出る場合は、ファイルを右クリックしてブロック解除してから実行してください。

# ドキュメント案内

この `docs/` は、現行の α版実装と、次期 `v0.2` 仕様を分けて管理するためのディレクトリです。

## 読み方

- 現行実装の整理を見る: `versions/v0.1-alpha/`
- 次期仕様を見る: `versions/v0.2/`
- 原文仕様を見る: `references/original_spec_v0.1.md`
- ルート `仕様指示書.md` は初期メモ兼一次資料として残しています

## 版の位置づけ

- `v0.1-alpha`: 現在のローカルWeb実装の実態整理
- `v0.2`: ハイブリッド構成の正式仕様

## 注意

- `v0.1-alpha` は実装事実を記録するスナップショットです
- `v0.2` は今後の実装判断の基準になる仕様です
- 実装変更時は、まず `v0.2` を更新し、その後必要に応じて `v0.1-alpha` の注記を最小限で直します

# v0.1-alpha 既知の問題

## 1. Python 3.14 / 3.12 の二重構成

現行実装は、バックエンド本体とWhisper実行環境が分かれています。

- 本体: Python 3.14
- Whisper: Python 3.12

この構成は試作としては動くものの、配布、再現性、保守性の面では不利です。

## 2. UI経由の初回モデル取得が不安定

- Whisperモデル未取得時、UIからそのまま初回実行しても安定して取得できないことがある
- そのため、モデルは事前取得を前提に運用している
- README上の初回自動取得説明は補足つきで読む必要がある

## 3. 認識品質の限界

- モデル精度に依存する
- 短いテスト音声でも語順や語尾が崩れることがある
- 話者分離は持たない
- 音声品質や間の取り方により、期待文言とズレることがある

## 4. 認識速度の限界

- 初回認識はモデル読込と推論で時間がかかる
- キャッシュが効けば速いが、未キャッシュ時は待ち時間が大きい
- 高精度モデルほど待ち時間は増える

## 5. 配布に向かない

- Python環境依存が強い
- モデル取得手順が必要
- 単純な「アプリを起動して使う」形にはなっていない
- 身内配布や共有運用には構成を見直す必要がある

## 6. Web共有がない

- プロジェクト保存はローカルディスクのみ
- プリセット保存もローカルディスクのみ
- 別PCや別ユーザーとの共有機能はない

## 7. ブラウザ制約

- 読み込んだ既存話者カードのファイル input は復元できない
- そのため、設定や内部参照は復元できても、音声欄やEXO欄にファイル名そのものは戻せない

## 8. α版としての位置づけ

この版は有効な検証実装ですが、本命運用向けではありません。  
次期 `v0.2` では、音声認識をローカルへ分離し、共有可能なWeb変換サービスへ再構成する想定です。

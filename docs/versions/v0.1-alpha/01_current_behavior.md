# v0.1-alpha 現行挙動

## 画面構成

現行UIは以下の3ブロックで構成されます。

1. プロジェクト設定
2. 話者設定
3. 生成と確認

補助機能として、保存済みプロジェクト一覧と話者プリセット一覧を持ちます。

## プロジェクト保存

- プロジェクト作成時に `project_id` を発行する
- プロジェクト設定は `data/projects/<project_id>/project.json` に保存する
- 画面上から `プロジェクト保存` を実行できる
- 保存済みプロジェクト一覧から再読込できる
- 保存対象は以下
  - プロジェクト設定
  - 登録済み話者
  - 最新の字幕セグメント

## 話者登録

- 話者ごとにカードを追加する
- 各カードで以下を設定する
  - 話者名
  - 音声ファイル
  - サンプル `.exo`
  - 認識JSON
  - 最大文字数/行
  - 最大行数
  - 最短表示秒数
  - 最長表示秒数
  - 出力レイヤー
- 登録済み話者は再読込時にカードとして復元される
- 既存カードは再登録対象にはせず、保存済み設定として扱う

## 話者プリセット

- 各話者カードからプリセット保存ができる
- プリセットは以下を持つ
  - 見本 `.exo`
  - 字幕ルール
  - 既定レイヤー
  - テンプレートプレビュー情報
- 保存先は `data/presets/<preset_id>/` 配下
- プリセット一覧から新規カードへ適用できる
- 読込済み話者カードでも、保存済みのテンプレート参照を使ってプリセット再保存できる

## Whisper ローカル認識

- 音声認識はローカルPC上で実行する
- 実行基盤は次の二重構成
  - バックエンド本体: Python 3.14
  - Whisper実行: Python 3.12
- Whisperは別プロセスのワーカーとして動く
- 認識モードは次を持つ
  - `tiny`
  - `base`
  - `small`
  - `medium`
- 認識結果は同一音声・同一モデルごとにキャッシュJSONへ保存される

## EXO出力

- 話者別テンプレートを複製して統合 `.exo` を生成する
- 出力時に差し替える主項目
  - `start`
  - `end`
  - `layer`
  - `text`
  - セクション番号
- 同時に以下も出力する
  - `output.srt`
  - `output.json`
- 出力先は `data/projects/<project_id>/exports/`

## テンプレート抽出

- `字幕テスト` 完全一致を優先候補とする
- ただし現在の実装では、テキストオブジェクトが1個だけならその内容をテンプレートとして採用する緩和を入れている
- これにより `字幕テスト_.exo` のような単一候補EXOを扱える

## レイヤー挙動

- 話者ごとに `base_layer` を保持する
- EXO出力時は、テンプレート内の親オブジェクト `layer` をプロジェクト側指定で上書きする
- これにより複数話者のレイヤー分離が可能

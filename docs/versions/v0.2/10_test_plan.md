# v0.2 テスト計画

## E2E

- ログインできる
- プロジェクト作成できる
- 話者ごとにSRTとテンプレートEXOを登録できる
- EXO生成できる
- 生成物をダウンロードできる

## 変換精度

- SRT時刻が正しくフレームへ変換される
- テンプレート見た目が保持される
- 本文差し替えが壊れない
- 複数話者統合時に時系列順が正しい

## レイヤー

- 2話者以上で別レイヤーを設定できる
- 出力EXOの親オブジェクト `layer` が話者設定に従う

## 共有・保存

- プロジェクト一覧が取得できる
- プリセット一覧が取得できる
- プリセットを別プロジェクトに適用できる
- プロジェクト更新後に再読込できる
- テンプレート原本をR2から再取得できる

## ローカル音声認識連携

- ローカルアプリで出したSRTをWebへ投入できる
- 音声認識エンジンの違いに関係なく、SRTが読めれば変換できる

## 異常系

- SRT不正
- EXO不正
- テンプレート候補不正
- プロジェクト設定不正
- 認証なしアクセス

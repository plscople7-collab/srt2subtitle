# v0.2 保存と認証

## 保存基盤

### D1

用途:

- プロジェクト
- 話者設定
- プリセット
- アセットメタデータ

方針:

- 一覧、検索、参照のためのメタデータを持つ
- バイナリ本体は持たない

### R2

用途:

- テンプレートEXO原本
- SRT原本
- 必要なら生成物キャッシュ

方針:

- バイナリ本体を保管する
- 再読込や複製の元データに使う

## R2 key設計

例:

- `templates/team_xxx/asset_xxx.exo`
- `srts/project_xxx/speaker_xxx/asset_xxx.srt`

## 認証

前提:

- 利用者は身内限定

方針:

- すべての共有APIは認証必須
- 初期版では細かい権限差は持たず、共有メンバー全員編集可を前提にする

## 共有権限

- プロジェクト: 共有メンバー全員が閲覧・更新可
- プリセット: 共有メンバー全員が閲覧・更新可
- 将来必要なら、所有者や閲覧専用権限を追加可能な設計にする

# v0.2 概要

## ゴール

`v0.2` の目的は、音声認識をローカルに分離しつつ、プロジェクトと話者プリセットをWeb上で共有できるハイブリッド構成へ移行することです。

## 背景

`v0.1-alpha` はローカル完結の検証実装として有効でしたが、以下の限界があります。

- 音声認識が重い
- Python実行環境が複雑
- Web共有がない
- 身内配布や共同利用に向かない

そのため、重い処理は各PCのローカルアプリへ寄せ、軽い変換と共有はWebへ寄せる再構成を本命仕様とします。

## 基本方針

構成は次の2段です。

```text
A. ローカル音声認識アプリ
音声/動画
↓
Whisper等で文字起こし
↓
話者ごとの .srt を生成

B. Web共有変換サービス
話者ごとの .srt
+ 話者ごとのテンプレート .exo
+ プロジェクト設定
+ 話者プリセット
↓
AviUtl用 output.exo を生成
```

## α版との違い

- 音声ファイルはWebの主入力にしない
- Webの主入力は `.srt`
- 共有対象はプロジェクトと話者プリセット
- 音声認識はローカルに閉じる
- Webは軽量なSRT→EXO変換器として扱う

## 対象ユーザー

- 身内メンバー内で同じテンプレートや案件設定を共有したい人
- AviUtl向け字幕EXOをまとめて生成したい人
- 音声認識そのものより、見本EXOを崩さず量産したい人

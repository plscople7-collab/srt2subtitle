# v0.2 要件

## 要件の主軸

`v0.2` は以下を満たす必要があります。

1. Web上でプロジェクトとプリセットを共有できる
2. 重い音声認識はローカルで完結する
3. Web上ではSRT→EXO変換だけを担う
4. AviUtl向けの見本EXOを安全に再利用できる

## 共有要件

- 共有範囲は身内限定
- プロジェクトは複数人が閲覧・編集できる
- 話者プリセットは複数プロジェクトから再利用できる
- プリセットとプロジェクトは別オブジェクトとして保存する

## 入出力要件

### Web入力

- 話者ごとの `.srt`
- 話者ごとのテンプレート `.exo`
- プロジェクト設定
- 字幕ルール
- 出力レイヤー

### Web出力

- `output.exo`
- `merged.json`
- `preview` 用データ

### ローカル入力

- 音声または動画

### ローカル出力

- 話者ごとの `.srt`

## 中間形式要件

- Web とローカルの接続形式は `.srt` に統一する
- 音声認識エンジンは Web 側の仕様に持ち込まない
- Whisper / faster-whisper / whisper.cpp / API 由来のSRTを同じ扱いにする

## 非機能要件

- Web側は軽量であること
- Cloudflare Workers の制限内で処理が収まること
- 音声認識モデルやGPU依存をWeb側に持ち込まないこと
- テンプレート `.exo` の未知パラメータを極力壊さないこと

# v0.2 ローカル音声認識アプリ

## 目的

ローカルアプリの役割は、音声や動画から `.srt` を生成することに限定します。

## 責務

- 音声/動画入力
- Whisper等による文字起こし
- 必要なら話者ごとのSRT分割補助
- 話者ごとの `.srt` 出力

## 非責務

- プロジェクト共有
- プリセット共有
- EXO生成
- Web変換

## 出力契約

ローカルアプリは、最終的にWebへ渡せる `.srt` を出力します。

前提:

- 1話者1SRTを原則とする
- SRTの本文はユーザーが最終修正してよい

## エンジン方針

- Whisper系を採用可能
- 実装は将来差し替え可能にする
- Web側仕様は、どの音声認識エンジンかを前提にしない

## 連携方針

- Webへは音声ではなくSRTを渡す
- 必要ならローカルアプリ側で「Webへ渡す用フォルダ出力」を持てるようにする

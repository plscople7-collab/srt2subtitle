# v0.2 Worker変換仕様

## 入力

- プロジェクト設定
- 話者設定
- 話者ごとのSRT
- 話者ごとのテンプレートEXO

## SRT parser

処理:

1. 字幕番号を読む
2. 開始/終了時刻を読む
3. 本文を読む
4. 空行までを1字幕単位とする
5. 話者IDをSRT単位で付与する

## EXO parser

処理:

1. セクション単位で読む
2. 対象テキストオブジェクトを特定する
3. 親オブジェクトと付随フィルタを保持する
4. 未知パラメータを壊さず保持する

## frame変換

処理:

1. `start_frame = round(start_sec * fps) + 1`
2. `end_frame = max(start_frame, round(end_sec * fps))`
3. 同一話者の重複は必要に応じて補正する

## template複製

処理:

1. 話者テンプレートを複製する
2. 本文を差し替える
3. `start`, `end`, `layer` を差し替える
4. セクション番号を連番で再採番する

## warning方針

警告対象:

- 長すぎる字幕
- 短すぎる字幕
- 改行調整不能
- テンプレート候補曖昧

## 出力

- 統合 `.exo`
- 変換済み内部JSON
- プレビュー用整形データ

## 制約

- 音声認識は扱わない
- Worker内で完結するのはテキスト処理とテンプレート複製のみ

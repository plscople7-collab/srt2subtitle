# v0.2 移行方針

## 目的

`v0.1-alpha` の検証実装から、Web共有前提の `v0.2` へ移るときの整理を明確にします。

## 持ち越すもの

- テンプレート複製方式
- EXO parser の考え方
- EXO writer の考え方
- frame変換の基本式
- 字幕ルールの考え方
- 話者プリセットという概念
- 話者ごとのレイヤー分離

## 捨てるもの

- Web側で音声ファイルを主入力にする設計
- Web側でWhisperを直接回す設計
- Python 3.14/3.12 二重構成
- UI上の認識モード選択
- Whisperモデル取得運用をWebに持たせること

## 分離するもの

- 音声認識はローカルアプリへ分離
- プロジェクト共有とプリセット共有はWebへ集約
- SRTを境界として責務を切る

## 移行手順

1. α版を `v0.1-alpha` として文書確定する
2. v0.2のデータモデルを先に確定する
3. EXO変換ロジックをWorkers向けに再実装する
4. 共有用の保存層をD1/R2へ移す
5. ローカル音声認識アプリを別責務として整理する
6. Web UIをSRT中心へ作り替える

## 互換方針

- α版のプロジェクトJSONをそのまま本番互換にはしない
- ただし、テンプレートEXOと字幕ルールの概念は引き継ぐ
- 既存ローカルプリセットは、必要ならv0.2用へ移行スクリプトを後から作れる余地を残す

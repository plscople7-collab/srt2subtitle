# v0.2 UI

## ダッシュボード

表示内容:

- プロジェクト一覧
- プリセット一覧
- 新規プロジェクト作成導線

## プロジェクト編集

項目:

- プロジェクト名
- fps
- 解像度
- 出力名
- 話者カード一覧

## 話者カード

各カードに持つ項目:

- 話者名
- SRTファイル
- 適用プリセット
- テンプレートEXO
- 最大文字数/行
- 最大行数
- 改行補正有無
- 出力レイヤー

表示補助:

- テンプレートから抽出したフォント
- サイズ
- 色
- 縁取り
- レイヤー

## プリセット適用

- 一覧から既存プリセットを選ぶ
- プロジェクトへ適用する
- 適用後に個別上書き可能にする

## 変換/出力画面

表示内容:

- マージ後字幕一覧
- 警告一覧
- 変換実行
- `.exo` ダウンロード
- `merged.json` ダウンロード

## UI方針

- 音声認識UIは持たない
- Whisperモデル選択UIは持たない
- SRTとテンプレートEXOの対応関係を明示する
- 共有と再利用を優先し、音声AI設定はWebに持ち込まない
